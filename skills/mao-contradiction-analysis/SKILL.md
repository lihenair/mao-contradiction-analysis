# 毛选看世界

写专栏，不是填分析框架。结构跟着**卡点**走：这篇被什么锁住了，标题就开在那里。需要对照时读 `examples.md`。

**核心句先成立，范畴后组织。** 读完应能用一句说清：这个动作在功能上是什么，真正没解决的是哪对矛盾。写不出这句，不要开工。

## 默认章法（可改名、合并，禁止空填）

推荐骨架来自能打出阅读量的成稿。第三节按卡点换肉，不要七节每节都有。

**导语**
- 先写日期和动作，不写百年变局。
- 立刻拆表面/实质（降级还是换岗，求和还是管理危机）。
- 用一句定性：这是功能上的战略退却 / 相持管理 / 进攻试探；并点出真正没解决的矛盾。
- 禁止用「棋手、棋盘、走钢丝、目标函数集合」开篇。

**一、为什么要做？最硬的事实**
- 制度、账本、权限、任期、海峡、军费、宪法。能换成数字或条文的，不要换成心理。
- 制度事实只支撑**功能定性**（相当于换岗、相当于把打击当谈判筹码），不支撑「他早有布局」「他最擅长」。
- 点一句毛选范畴可以，但范畴是组织事实，不是另起一段空论。

**二、真正的火药桶（内因）**
- 内因必须有肉：死了谁、谁上街、谁缺授权、哪份民调、哪条法案。
- 外因（制裁、斡旋、外部支持）是条件，必须写清它怎样通过内因起作用。
- 有第三条战线就写成**传动杆**（开峡绑黎巴嫩、换岗绑最短选举周期），禁止写成区域名词表。

**三、对手或选项的现状**
- 卡在反对派，就写整合到哪一步、缺什么核心。
- 卡在军事选项，就写威胁的边际可信度，而不是「会不会打」的预言。
- 这一节的标题跟着卡点改，不必叫「反对派」。

**四、时间窗口**
- 选举日、最短法定周期、会期、停火时限——用时间差做什么。
- 两套解释若都能成立，必须说明它们对**时间窗口的含义不同**（换岗手续 vs 压缩对手整合）。解释可以长短不一，但要能改写这一节，不能一句话处死。

**五、大国夹缝**
- 外交动作如何被带回国当政治资本。方向可以写，幅度没证不要写死（「中俄支持有限」要有依据，不能一句打发）。
- 格局判断若要出现，就放这里当夹缝，不要单独开「格局层」章节。
- 历史类比可以落在这里：相同结构性困境 + 关键差异。类比是参照系，不是「当年解体所以这次也解体」。

**六、数据黑箱**
- 两套判断、两套民调、可观测 vs 不可观测，写在这里。
- 公开信息够用的：成本、通航、口风、任期、法定日期。不够用的：谁拍板、真实支持率、库存还在哪。
- 口头信号 ≠ 政策落地。数据要带口径（季度同比不是开战以来累计）。
- 用黑箱拦住预测，不要另写三条情景剧充条件推演。若写路径，每条必须对应不同结果，禁止「无论如何都会」。

**七、收束**
- 主要矛盾：哪一对不解决，其他操作都是换岗、换词、换时间。
- 内因 / 外因；操作有没有碰到根本问题。
- **证伪条件写死**：出现哪些可核对的事实，这篇的主判断就失败。没有证伪条件，收束不合格。
- 可用：「主导局势的，终究是内部矛盾的发展逻辑。」「分析的价值在于识别变量与推演条件，而非给出单一预测。」
- 禁用：「他最擅长……」当事实；「下一次将不再可控」这类没有变量的恐吓；「无论怎样都会同一结局」。
- 文末：毛选看世界，下期继续。加公开信息、不站队、结果未产生、口径说明。

## 硬闸

1. 行为 ≠ 结果。辞职、停火、放话已发生；选票、通航、合法性是否被覆盖，待验证。
2. 功能 ≠ 动机。操作逻辑可推演；是否主动设计不可证伪。两句分开写。
3. 方向 ≠ 幅度。反对派「在整合」不是已经有统一领袖；威胁「在折旧」不是军事选项关闭。
4. 变量 ≠ 预测。黑箱就是黑箱。价值在识别变量和证伪条件。
5. 替代解释的任务是**拦住越界预测、改写时间窗口**，不是凑成与主解释对等字数，也不是写完立刻否定。
6. 主要矛盾可以在收束才点明，但前面事实必须撑得住；若换一个主要矛盾，时间窗口或传动杆应跟着变——点明即可，不必另开作业题。

## 红旗：写到这些就停

- 先写「格局层/区域层/事件层」或「棋手棋盘」
- 「真正动机是」「主动转化成幕后操盘手」「他最擅长把危机拖进程序」
- 替代解释只有一句「但显然不是」
- 并列条件后收成同一必然结局
- 用「可能不再可控」代替证伪条件
- 把口风写成政策，把季度数据写成终局
- 历史类比只有警告、没有关键差异

## 交稿前过一遍

- [ ] 开篇是日期和动作，不是格局填空
- [ ] 有一句核心句：功能上是什么，没解决的是哪对矛盾
- [ ] 最硬事实只支撑功能定性，没有「真正动机 / 最擅长」
- [ ] 内因有具体事件；若有第三条线，写成传动杆
- [ ] 替代解释能改写时间窗口的含义，不是一句带过
- [ ] 黑箱拦住了预测；没有「无论如何」或无变量的恐吓收束
- [ ] 收束有可核对的证伪条件
- [ ] 类比写了相同困境 + 关键差异（若用了类比）
- [ ] 口风与政策、数据口径已经分开

## 边界

- 有理论偏好（矛盾辩证法），不装中立。
- 主要矛盾的选择是主观的，但要能被证伪条件打脸。
- 历史类比不是因果证明。
- 夹缝里只讲方向和条件，不提前宣布终局。
