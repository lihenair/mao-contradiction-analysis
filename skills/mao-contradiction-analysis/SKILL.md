# 毛选矛盾分析框架（从格局到事件）

用矛盾分析法分析国际格局与具体地缘事件。严格按以下结构与纪律执行，不得跳过强制环节。需要对照写法时读 `examples.md`。

## 一、分析层次（强制三层，不可乱跳）

1. **格局层**（百年未有之大变局）
   - 必须回答：谁在上升、谁在下降、谁在重组？
   - 旧秩序的裂缝在哪里？新力量的生长点在哪里？
   - 分析“敌我友”关系变化：主要对手、中间力量、可争取力量。
   - 用矛盾论组织，但只讲方向，严格区分方向与幅度。不提前预测结果。

2. **区域层**
   - 区域内力量格局：谁是棋手、谁是棋盘、谁在走钢丝。
   - “根据地”与“中间地带/游击区”关系。
   - 区域内主要矛盾是什么？外部力量如何介入？
   - 必须为事件层留出接口，不把全球规律直接套到具体事件。

3. **事件层**
   - 具体动作的操作逻辑：谁在什么时候做了什么、为什么在功能上会这样做、效果待验证。
   - 区分战术动作与战略意图（操作逻辑可推演，真实动机不可证伪）。
   - 核心问题：这个动作解决了什么矛盾、又暴露了什么矛盾？

## 二、推导链条（按顺序执行）

1. **现象识别**
   - 先写清发生了什么。不停留在表面判断（“下台”“降级”），追问动作的性质。

2. **性质定性**
   - 用毛选范畴定性（战略退却/进攻/相持、主动转化/被迫应对等）。
   - 必须有制度事实、时间窗口、反对派状态等证据支撑。
   - 若证据同时兼容多种定性，标注“动机不可证伪”，不强行二选一。

3. **替代解释检验**（强制，紧接定性之后）
   - 至少提出一个有竞争力的替代解释（可来自制度路径依赖、理性选择、信息不对称、短期危机管理、派系妥协等）。
   - 比较证据强弱：哪个解释更能覆盖已观察到的关键事实？为什么当前更支持或无法排除？
   - 不要求必须跳出矛盾论，但必须认真对待竞争力。
   - 替代解释必须得到与主解释同等论证篇幅，敷衍带过视为未通过。

4. **矛盾定位**
   - 这个动作在矛盾结构中处于什么位置？解决主要矛盾还是次要矛盾？
   - 主要矛盾判定标准（在选定之前使用，而非事后证明）：
     - 哪个矛盾不解决，其他矛盾就无法有效推进？
     - 哪个矛盾演变速度最快、影响面最广？
     - 哪个矛盾的激化会直接触发当事人的核心应对动作？
   - 必须写明：如果选另一个作为主要矛盾，分析会如何不同。

5. **当事人视角**（独立环节）
   - 只推约束条件与可见行动空间。
   - 不推内心真实动机。
   - 目标函数最多写成“可能的目标函数集合”，不写成单一确定目标。

6. **条件推演**
   - 识别关键变量，并列呈现不同条件下的不同结果。
   - 只对最关键的2-3个变量展开并列路径；其余用压缩写法标出方向。
   - 每条路径必须对应不同结果。禁止“无论如何都会……”式收束。若并列路径最终收敛到同一必然结果，视为伪条件化。
   - 禁止只写“最可能”路径后当作既定事实。条件化推演 ≠ 预测。

7. **历史类比**
   - 必须写清：相同的结构性困境是什么 + 关键差异是什么。
   - 类比是参照系，不是因果证明。历史不会重复，但结构性困境会重演。

## 三、四条核心纪律（全程强制）

1. 不把“行为”等同于“结果”。行为已发生，效果待验证。
2. 不把“动机”当作“事实”。操作逻辑可推演，真实动机不可证伪。必须分开表述。
3. 不把“方向”当作“幅度”。方向成立 ≠ 幅度已证。
4. 不把“变量识别”当作“结果预测”。分析价值在于识别变量与推演条件，而非给出单一预测。

## 四、操作逻辑 vs 真实动机（表述模板）

- 正确示例：
  “从制度事实（任期限制、议会制实权、选举时间窗口）看，这个动作在功能上相当于一次战略退却。”
  “至于当事人是否主动设计了这一退却，现有证据无法证伪，也不应当作已证实的事实。”

- 禁止把两者混写在同一判断句中。

## 五、核心范畴与收束句式

**核心范畴**：
- 主要矛盾 / 次要矛盾
- 内因 / 外因
- 矛盾的主要方面 / 非主要方面
- 矛盾的普遍性 / 特殊性
- 战略退却 / 战略进攻 / 战略相持
- 根据地 / 中间地带 / 游击区

**推荐收束**：
- “主导局势的，终究是内部矛盾的发展逻辑。”
- “分析的价值在于识别变量与推演条件，而非给出单一预测。”
- “历史不会重复，但结构性的困境会重演。”

## 六、框架边界（必须标注）

- 本框架有明确理论偏好（矛盾辩证法），不追求价值中立。
- 主要矛盾的选择是主观的，但选择过程必须透明。
- 操作逻辑可推演，真实动机不可证伪。
- 历史类比是参照系，不是因果证明。
- 格局层只讲力量对比变化与裂缝/生长点，不提前给出终局判断。

## 七、写作检查清单（每篇文章强制过一遍）

- [ ] 三层结构完整且顺序正确
- [ ] 替代解释检验已做且有竞争力
- [ ] 替代解释得到了与主解释同等论证篇幅（敷衍带过视为未通过）
- [ ] 主要矛盾选择理由已写明 + 替代选择影响已说明（判定标准在选定前使用）
- [ ] 当事人视角只涉及约束与行动空间
- [ ] 条件推演并列呈现，每条路径对应不同结果，无“无论如何”式收束
- [ ] 历史类比写了相同困境 + 关键差异
- [ ] 操作逻辑与真实动机已分开表述
- [ ] 无“行为=结果”“方向=幅度”“变量=预测”的越界
