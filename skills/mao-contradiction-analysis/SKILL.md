# 毛选看世界

写专栏，不是填分析框架。先定文类，再开写。对照 `examples.md`。

**核心句先成立，范畴后组织。** 写不出一句核心句，不要开工。

**上来三到四段，必须通过路人测试。** 找一个没读过事实箱的人，问「这篇文章想说什么」。答得出本篇核心句，才能往下写。答出「好像讲了很多事」，就是导语堆事件、结论太靠后。多线周尤其如此：先一句实质，再用两三件支撑它的动作。其余事实放到能扣回主线的节里。禁止「战报→会→文件→编制→所以呢」。

**每节结尾扣回本篇主线。** 写船、写编制、写别的海峡，都要当场回答「这和核心句有什么关系」。扣不上就删，或压成一段背景。不要另起一章去讲一件只是「同一周发生」的事。

**毛选用来推句子，不贴标签。** 「主要矛盾」「内因外因」出现时，因果关系必须已经写出来：外因（前线、海峡、对手加码）怎样穿过内因（库存、选民、本国防空）把动作卡住。禁止收束段才把三个词堆上去。读者冲着「毛选」来，要看见工具在干活；冲着「看世界」来，删掉标签句子仍读得懂。

**每篇独立成稿。** 不写「上篇写过」「同一季节的天气」。要接别的战场，只用本篇材料里已经出现的通道、库存、海峡，一句说完。没读过前篇的人，必须仍能读懂这一篇。

## 动笔前：多源事实箱（强制）

能抓公开网页就抓。优先 Reuters / AFP / AP / DW / Al Jazeera / BBC / 新华社英文，再看当事方电视台和外交部。付费全文、需登录的社媒、非官方「内部接口」不要硬闯；通稿被转载到 Yahoo、印度媒体等处也可以用，但数字仍要标原口径。

事实箱只记这些，记完再写结构：

| 栏 | 写什么 |
|----|--------|
| 已核对着 | 日期、地点、谁承认「我方出手」 |
| 单方口径 | 谁说几死几伤、是否含儿童、目标是市集还是军营 |
| 未核实 | 独立核查是否闭合；匿名军源；「伊朗专家」「大战果」 |
| 同季天气 | 通稿里和这件事同一周的通道、封锁、攻势（如曼德海峡、霍尔木兹、能源出口） |
| 地理 | 这块地方为什么不是普通地点（政府控制的城市？前线贴着市集？轰炸机基地？） |

规则：数字跟着说话的人走。胡塞卫生部的 7 死 40 伤，不要写成「已确认平民死亡」。政府说「我方战机」，不要写成「沙特已经认领」。未具名军源的「附近新设营地」「二次爆炸」，保留「路透/新华引述」。一方外交部致函联合国，是叙事动作，不是伤亡鉴定。

没有事实箱就开写，必然口风当事实。

## 先选文类，禁止拿错骨架

| 文类 | 何时用 | 核心句要回答 |
|------|--------|----------------|
| **主篇** | 主角自己出手：换岗、谈+打、提前选举 | 动作功能上是什么，没解决的是哪对矛盾 |
| **侧翼·后勤反噬** | 战火溢到盟友本土、基地、后勤（Fairford） | 外因贴在哪块资产上，穿过哪几层内政，如何反挤主角 |
| **侧翼·边缘燃烧** | 代理人线、次级战区、红海/也门（塔伊兹） | 主战场僵住时，这条线如何维持「还在打」，又如何按住总开关 |

主次：侧翼**不改写**主矛盾。Fairford 不是「英国决定美伊」；塔伊兹不是「也门变成新主战场」。

侧翼禁止互套：Fairford 不要写成 50 天闪电战；塔伊兹不要写成英国反恐三层管道。两类都是侧翼，机制不同。

系列最多点一句上一篇，且不得依赖那一句才能读懂本篇。不要每篇从百年变局重起，不要为过旧清单去补「棋手棋盘」。

## 主篇章法（换岗、谈+打、多线周）

导语：核心句先落地。单动作周可以「日期动作 → 表面/实质」；多线周必须「实质 → 两件支撑它的动作 → 看得见的结果」。不要把战场、峰会、编制一次性倒进前三段。

一、为什么要做：制度、账本、任期、海峡。只支撑功能，不支撑「他最擅长」。  
二、火药桶：内因有肉；传动杆写清。  
三、对手或选项：标题跟着卡点改。  
四、时间窗口：两套解释必须能改写这一节的含义。  
五、夹缝：外交如何当国内资本；类比要有关键差异。  
六、黑箱：口径、口风≠政策。  
七、收束：证伪条件写死。

## 侧翼·后勤反噬（Fairford）

导语：现场 + 这块地方不是普通军营 + 如何按进东道国内政。未定论保持未定论。

一、外因贴到资产上。话语从刑事案件滑向同盟责任，就是外因开始通过内因起作用。  
二、内政管道分层（证据门槛、民意落差、叙事争夺）。概念如**同盟成本内化**，每层要有可观察摩擦。  
三、接到主结构。反向溢出：成本溢回提供后勤的盟友本土。主次不变。  
四、收束：个案可能另有动机，不影响「资产仍服务该行动则摩擦会反复」。信号写成不同结果，不是监测清单。

## 侧翼·边缘燃烧（塔伊兹）

不要套 Fairford 的「围栏 / 保释 / 议会辩论基地」。

**导语**
- 先钉事实箱：两套现场定义并列（市集 / 军营），数字标出处，独立核查写明未闭合。
- 若前线地理允许两套说法同时成立（摊位贴着营地），把这句空间关系写进导语——这是「边缘」的地理，不是修辞。
- 核心句：单独看是内战炮火；放进主结构，才是边缘燃烧。

**一、边缘在燃烧什么**
- 先给机制，不要先填「外因贴上资产」。**边缘燃烧**：主战场打不出终局、又停不起示弱时，用一条可切割的代理人线维持存在感；要看得见，又要按得住。
- 三个特征必须能在材料里对上：烈度可控（空袭、声明、局部推进，不是本土对等全面战争）；叙事拉满（平民/儿童 vs 军营/车辆）；与主战场同频（通稿里的通道、封锁、攻势是否同一季节——有则写，无则不要编）。
- 次级战区的战火，叙事却接到大国三角上，这才叫边缘。

**二、谁通过谁起作用**
- 外因：主战场僵局 + 能源/航运通道不确定。
- 内因：各方国内约束（要安全、又怕 2015 式泥潭；要存在感、又怕灭顶打击；要施压、又不宜被写成点燃海湾全面战争）。外因通过这些内因，把战场固定在「烧着但不烧穿」。
- **替代解释必须能改写归档**：纯内战推进、边境清剿，往往更能覆盖「这一弹」；主解释多覆盖的是「抽屉已经在滑」。两条可以同时为真（弹是前线弹，抽屉是地区弹）。不要求和主解释对等字数，但要写明各覆盖什么、覆盖不了什么。禁止一句「但显然是代理人」。
- 结构位置 ≠ 指挥链。可以说「被读成伊朗相关杠杆」；不能在通稿未证实操作关系时写成「德黑兰下了这道弹」。

**三、接到主结构**
- 接到主结构时只补本篇已经立住的那一句：僵局需要边缘提供「仍在打」的证据。不要点名「某篇写过」。没读过主篇的人，仍须读得懂这一篇。
- 各方各吃一口存在感，成本写清：**主要由当地平民与地方武装承担，战略信号由地区大国和注意力市场消费。** 「中间态对决策者最省事」必须标明——不是对死者最省事，也不是预言中间态必然持续。
- 类比（2015 有限空袭周期、红海商船袭扰）：相同困境 + 今日差异（霍尔木兹已是灰区、谈判与威胁并行、还有 Fairford 式同盟成本）。

**四、收束**
- 主要矛盾往往是：主战场的僵局管理 ↔ 代理人线必须维持有限存在感。
- 个案查不清（市集还是军营）不影响结构判断；但本案核查仍可留一条信号。
- **可观察信号必须写成并列路径，每条对应不同结果。** 监测清单不合格。例如：报复停在前线 → 边缘低频循环、主谈判不必改口；爬上红海/能源并被写成系统封锁 → 向主阀爬一格；并入伊朗文件并公开搁置谈判 → 余烬变成日程本身。禁止收成「无论如何都是边缘燃烧」。
- 下期预告要具体（双海峡、欧洲多线）。

## 硬闸

1. 行为 ≠ 结果。  
2. 功能 ≠ 动机。国家指使未证不要写成事实。  
3. 方向 ≠ 幅度。挂钩在争夺不是已经成功。  
4. 变量 ≠ 预测。  
5. 替代解释改含义（时间窗口或归档抽屉），不对等凑字，不一句处死。  
6. 侧翼不推翻主矛盾；两类侧翼不互套。  
7. 结构判断可在个案未结时成立，必须把「可能另有动机 / 可能只是内战弹」说在明处。  
8. 没有多源事实箱，不得开写。

## 红旗：写到这些就停

- 格局层 / 棋手棋盘开篇  
- 「真正动机」「他最擅长」「伊朗干的」（未定论时）  
- 把塔伊兹写成 Fairford，或把 Fairford 写成也门战报  
- 替代解释只有一句「但显然不是」  
- 三条信号没有三种结果；「无论如何都会」  
- 一方卫生部数字写成已确认平民死亡  
- 为过旧清单去补百年变局或对等字数

## 交稿前过一遍

- [ ] 事实箱在先：多源、口径、未核实、同季天气、地理
- [ ] 文类选对，侧翼没有互套
- [ ] 开篇通过路人测试：没读过原文的人能说出核心句
- [ ] 多线周：结论在前；每节结尾扣回主线；扣不上的事实已删或压成背景
- [ ] 矛盾分析在推句子，不是收束贴标签；不依赖前篇才能读懂
- [ ] 机制立住（换岗 / 同盟成本内化 / 边缘燃烧），不是形容词
- [ ] 功能与动机分开；未定论保持未定论
- [ ] 替代解释能改写时间窗口或归档抽屉
- [ ] 收束路径对应不同结果；有证伪或可观察信号
- [ ] 成本由谁承担写清了（若是边缘篇）
- [ ] 类比若用了，有相同困境 + 关键差异

## 边界

- 有理论偏好（矛盾辩证法），不装中立。
- 主要矛盾主观，但要能被路径/证伪条件打脸。
- 历史类比不是因果证明。
- 能抓的公开通稿要抓；抓不到的不要编。
