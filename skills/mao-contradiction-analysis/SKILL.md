# 毛选看世界

写专栏，不是填分析框架。先定文类，再开写。正反例在 `examples.md`。不要把某一篇的句子写进规则。

## 成稿纪律

下一篇从这里起，不从上一篇的改稿批注起。

1. **一句核心句，先于事实。** 写不出陌生人能复述的一句，不要分节。同一周叠了好几件事：先这句，再用两件动作当证据，然后给一个看得见的结果。其余后置。禁止「战报 → 会 → 文件 → 编制 → 所以呢」。
2. **同一周发生，不等于属于这篇。** 船、编制、另一条海峡，写进去之前先问：删掉它，核心句还成不成立？不成立就留，且本节最后一句回到核心句。成立就删，或压成一句背景。
3. **正文只写给没读过前篇、没看过事实箱的人。** 口径订正、技能禁令、「上篇写过」留在稿外。抽象词出现之前，读者手里已经有具体名词：弹、文件、岗位、基地。系列最多一句，删掉它这篇仍通。陌生人测试用在每一句，不只用在开头。只靠这一句和上一句，要知道谁在说话、在跟什么比。不知道，就补上那半个背景，不要把结论再说一遍。跟改稿的人说话（「先要说清」「文中没有这个数」）也算没通过。
4. **毛选是因果句，不是栏目装饰。** 要写主要矛盾，就写成两股对不上的力，并写出外因怎样穿过内因把动作卡住。删掉「主要矛盾」「内因」「外因」，句子仍成立，才算用上了。只在收束贴这三个词，删。
5. **纲只有毛选。其他只当目，没有第二个纲。** 国内制度、账本、岗位、基地、下一档日期、现场定义，用来把因果句写硬，不另立分析框架。不要开学派栏目，也不要按国名单轮换填空。删掉学派名，传动杆还在，才算用上了。升格成第二套纲，删。

**目的边界（防洞察变窄）。** 当代机制（身份叙事、损失计算、否决点、议程争夺、安全恐惧的内生化）可以写，但必须化成可观察的传动杆：谁在什么岗位、什么文件、什么日期、什么现场定义上卡住了动作。允许写成具体句子，禁止挂牌成节、成栏目、成第二套组织逻辑。检验标准不变：删掉所有学派/理论名称，句子的因果仍成立，才算当目用上了；否则视为另立一纲，删。

**执行防走私。** 用制度、岗位、日期等具体名词组织全文，但主轴已经不是「两股对不上的力 + 外因如何穿过内因」，仍视为第二套纲。交稿前加问一句：这一节的组织逻辑，去掉所有具体名词后，还是不是矛盾分析在驱动？不是，就回炉。

**对象换了，纲不换。** 俄与中、美、欧同一套；北约、上合、金砖与欧盟同一套。有动作、有事实箱才写。国家的内因仍是制度、账本、岗位；大组织的内因是成员国库存、表决程序、会费和秘书处权限，不当棋手。不按大国、大组织名单排队。对象换了就另立克里姆林宫学或联盟理论，删。

**改稿分开。** 治本才改本文件：读者说不出主线；某节删了核心句仍在；范畴词没有因果；另立第二套纲；同一类句子病反复出现（缺背景、作者注、同一判断说两遍）。主线、缺背景、作者注、说两遍，改第 3 条。另立第二套纲，改第 5 条。不把单个词写成禁令。单个标题、单句挪位、某节再压短，只改这一篇。

## 搜集：宽进，窄用

搜集是为了不让核心句建立在转述上。同一周的相关新闻收进事实箱，不自动进正文。

按这个顺序，够用就停：

1. **原件。** 演讲全文、法令、战报、正式口径。预告、标题、二手快讯不能代替原件。
2. **时间。** 反应在原件之前还是之后。对着传闻说的话，单独标，不要和后来的文本当成已经对打。
3. **数字。** 谁估算的、口径是什么（额外还是总计、哪一年）、当事人接没接、有没有给自己的数。
4. **下一档日期。** 预算、峰会、核查、选举。没有这一档，路径就没有试金石。
5. **停止。** 新材料不再改变「谁做了什么」、核心句、或某一条路径，就停。再搜只是在加背景。

## 事实箱（动笔前，不进正文）

能抓公开网页就抓。优先 Reuters / AFP / AP / DW / Al Jazeera / BBC / 新华社英文，再看当事方电视台和外交部。付费墙和需登录的页面不要硬闯。转载可用，数字仍标原口径。

| 栏 | 写什么 |
|----|--------|
| 已核对着 | 日期、地点、谁承认「我方出手」 |
| 单方口径 | 谁说几死几伤、是否含儿童、目标是什么 |
| 未核实 | 独立核查是否闭合；匿名军源 |
| 同期背景 | 同一周的通道、封锁、攻势。只留能改写核心句的 |
| 地理 | 为什么不是普通地点 |

数字跟着说话的人走。卫生部的死伤数不要写成「已确认平民死亡」。政府说「我方战机」，不要写成第三方已经认领。未具名军源保留「路透/新华引述」。一方致函联合国是叙事动作，不是伤亡鉴定。

正文里出现的数字，要写出是谁的数、对方怎么接、对方有没有给自己的数。不要只写「演讲里没有这个数」：那是在向改过稿的人做订正。对方驳回的是一个约数时，写原估算的口径，不要把约数写成他的方案报价。

两个人的话放在一起之前，先看是不是同一份文本。会前对着传闻说的话，不是已经在反驳后来的讲稿。若仍是不同的主张，就写成两句具体的话。不要加「框架错位」这个标签。

表格、订正句、同期背景清单留在事实箱。进正文的是口径句：谁说的、说了什么、核查闭没闭合。边缘燃烧必须把两套现场定义写成这种句子，否则读者会把单方数字读成事实。不要把表格改写成来源清单。

核心动作（谁、何时、做了什么）没有公开通稿或当事方正式口径，就不要开专栏。伤亡、动机、毁伤只有匿名来源：可以写已经核对着的动作，并写明未闭合；核心句不得依赖那组数字。抓不到不要编，也不要用预警把空事实箱写成一篇。

## 先选文类

| 文类 | 何时用 | 核心句要回答 |
|------|--------|----------------|
| **主篇** | 主角自己出手：换岗、谈+打、多线周 | 动作功能上是什么，没解决的是哪对矛盾 |
| **侧翼·后勤反噬** | 战火溢到盟友本土、基地、后勤 | 外因贴在哪块资产上，穿过哪几层内政 |
| **侧翼·边缘燃烧** | 代理人线、次级战区 | 僵局下这条线如何维持「还在打」，又不烧穿 |

侧翼不改写主矛盾。两类侧翼不互套：后勤反噬不是 50 天换岗；边缘燃烧不是东道国反恐程序。

## 章法

节题跟着本篇卡点走。两套解释、三条路径、接到主结构，用得上才写，不是配额。材料里没有的节，不要凑。

**主篇。** 单动作：日期动作，接着表面/实质。多线周：核心句，两件证据，看得见的结果。后面只留用得上的：功能（制度、账本、任期，不写「他最擅长」）、内因与传动、对手卡点、两套能改写本节含义的解释、收束。

**后勤反噬。** 导语：现场、这块地方不是普通军营、未定论保持未定论。外因贴到资产上，再穿过可观察的内政层（证据门槛、民意落差、叙事争夺）。成本溢回提供后勤的盟友，主次不变。个案可以另有动机；资产仍服务该行动，摩擦就会反复。

**边缘燃烧。** 导语先钉两套现场定义和出处，独立核查未闭合就写明。机制：主战场打不出终局、又停不起示弱，用一条可切割的线维持存在感，要看得见，又要按得住。纯内战或边境清剿往往更能覆盖「这一弹」；边缘燃烧多覆盖的是地区抽屉。两条可以同时为真。结构位置不是指挥链。成本主要由当地人承担，信号由大国消费。

**收束。** 路径并排，每条一个不同结果。禁止「无论如何都是」。栏目固定收在「毛选看世界，下期继续」和利益声明。这是格式，改内容时保留。不要为了预告具体而另编下一期题目。

## 硬闸

1. 行为 ≠ 结果。
2. 功能 ≠ 动机。国家指使未证，不要写成事实。
3. 方向 ≠ 幅度。
4. 变量 ≠ 预测。
5. 替代解释要能改写含义，不一句处死，也不对等凑字。
6. 侧翼不推翻主矛盾；两类侧翼不互套。
7. 个案未结时结构判断仍可成立，但必须把「可能另有动机」说在明处。
8. 没有事实箱，不得开写。
9. 纲只有毛选。其他只当目，不另立框架，也不用具体名词走私第二套组织逻辑。

## 红旗

- 格局层、棋手棋盘开篇
- 「真正动机」「他最擅长」；未定论写成「伊朗干的」
- 拿错文类骨架
- 替代解释只有一句「但显然不是」
- 路径没有不同结果
- 单方死伤数写成已确认
- 为同一周的事硬凑一节；系列接头；编辑黑话；收束才贴「内因外因」
- 「文中没有某数字」这种订正句；把会前传闻和后来的文本写成已经在争同一件事
- 第二套纲：学派开节、理论栏目、国名巡阅填空；用具体名词把第二套组织逻辑撑起来；按大国、大组织名单排队；把联盟写成棋手

## 交稿前

- [ ] 陌生人只读开头，能说出核心句
- [ ] 任意一句只靠它和上一句，能知道谁在说话、在跟什么比
- [ ] 每一节删掉都会伤到核心句；伤不到的已删或压成一句
- [ ] 正文是口径句，不是事实箱表格；没有订正黑话和前篇接头
- [ ] 矛盾句去掉范畴词仍然成立
- [ ] 功能与动机分开；口径跟着说话的人
- [ ] 收束路径对应不同结果
- [ ] 纲只有毛选；删掉学派名，传动杆还在
- [ ] 去掉具体名词后，组织逻辑仍是矛盾分析在驱动

## 边界

有理论偏好，不装中立。偏好落在毛选这一纲上。其他学派可以化进传动杆，不得并列成纲，也不得用具体名词把第二套组织逻辑撑起来。对象换成俄或北约，纲不换。主要矛盾是判断，要能被后面的路径打脸。历史类比不是因果证明。抓得到的公开通稿要抓；抓不到的不要编。
