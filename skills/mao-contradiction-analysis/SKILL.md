# 毛选看世界

写专栏，不是填分析框架。先定**文类**，再开写。对照 `examples.md`。

**核心句先成立，范畴后组织。** 读完必须能用一句说清。写不出这句，不要开工。

先判断文类，禁止拿错骨架：

| 文类 | 何时用 | 核心句要回答 |
|------|--------|----------------|
| **主篇** | 主角自己出手：换岗、谈+打、提前选举 | 这个动作功能上是什么，真正没解决的是哪对矛盾 |
| **侧翼 / 续篇** | 战火溢到盟友本土、基地、后勤、第三方内政 | 外因贴在哪块实体资产上，穿过哪几层内政管道，如何反挤主角行动空间 |

主次关系：侧翼篇**不改写**主矛盾。Fairford 证明的是外因如何在盟友国内制造新内因，不是改写成「英国决定美伊」。

系列可点上一篇、预告下一篇，不要每篇从百年变局重起。

## 主篇章法（换岗、谈+打）

可改名、合并，禁止空填。第三节按卡点换肉。

**导语：** 日期和动作 → 表面/实质 → 功能定性 + 没解决的矛盾。禁止棋手棋盘、目标函数集合、格局层开篇。

**一、为什么要做？最硬的事实**  
制度、账本、权限、任期、海峡、军费、宪法。只支撑功能定性，不支撑「他最擅长」「早有布局」。

**二、真正的火药桶（内因）**  
内因要有肉。外因必须写清怎样通过内因起作用。第三条战线写成传动杆，禁止区域名词表。

**三、对手或选项的现状**  
反对派写整合到哪一步；军事选项写威胁的边际可信度。标题跟着卡点改。

**四、时间窗口**  
用时间差做什么。两套解释若都能成立，必须对时间窗口含义不同（换岗手续 vs 压缩对手整合），不能一句话处死。

**五、大国夹缝**  
外交如何被带回国当政治资本。方向可写，幅度没证不写死。类比：相同困境 + 关键差异。

**六、数据黑箱**  
两套判断、可观测 vs 不可观测。口风 ≠ 政策。口径要标明。用黑箱拦住预测；若写路径，结果必须不同，禁止「无论如何都会」。

**七、收束**  
主要矛盾；有没有碰到根本问题；**证伪条件写死**。禁用「他最擅长」当事实、无变量的恐吓收束。文末：下期继续 + 公开信息、不站队、口径。

## 侧翼 / 续篇章法（Fairford 这一类）

不要套主篇的「为什么要辞职 / 50 天闪电战 / 两套民调」。套了就是写砸。

**导语**
- 现场：时间、地点、谁被抓、控什么罪、是否保释、官方说了什么、媒体说了什么、当事方否认什么。
- 立刻写清这块地方**不是普通地点**（例如：远程轰炸机从这里参与对伊相关行动）。
- 核心句：一次靠近围栏的动作，如何把主战场按进东道国的国内安全议程。
- 未定论就写未定论。未具名消息归未具名，官方未定论就不要写成「伊朗干的」。

**一、外因已经贴到资产上**
- 主战场在哪，后勤节点在哪。这块资产一旦被叙事成作战资产，就可能被说成报复对象——这是外因。
- 外因不会自动变成东道国政治危机，必须点出它要穿过哪些内政管道（反恐法、社区、执政合法性、同盟义务）。
- 话语从「刑事案件」滑向「国家安全与同盟责任」，就是外因开始通过内因起作用的时刻。

**二、内因管道，分层写**
- 先给一个能站住的概念（如**同盟成本内化**：出基地出通道的国家，必须用国内政治消化安全与政治成本；消化过程反过来制约承诺）。概念是组织器，每层必须有可观察摩擦，禁止只有定义。
- 层数随材料，通常 2–4 层。Fairford 成稿是三层：证据门槛（速捕又保释说明公开证据链可能未闭合）；同盟义务 vs 家门口疏散的民意落差；代理/叙事争夺（挂钩尚未成为共识，就不要写成已经生效的战略杠杆）。
- 没有内政管道，中东只是电视新闻；有了管道，才变成预算、选票、同盟裂缝。

**三、接到主结构**
- 点明上一篇主判断（例如：美伊被两国国内政治锁死，谈判是管理工具）。侧翼只补充**第三方内政如何被卷进来**。
- 分别写对主角 A、主角 B、东道国意味着什么。杠杆是否生效，取决于舆论挂钩是否稳定，尚未共识就写尚未共识。
- 可升一层概念（如代理战争的**反向溢出**：成本溢回提供后勤的盟友本土），但主次不变：主导局势的仍是主角国内约束。侧翼证明的是：外因附着在同盟领土的实体资产上，会在盟友国内制造新内因，反挤主角行动空间。

**四、收束**
- 外因是条件，内因是根据，外因通过内因而起作用。
- 本案最终可能被定性为未遂、夸大或另有动机——**不影响结构判断**（只要资产继续服务于该行动，类似摩擦会反复出现）。结构判断与个案定性必须分开。
- **可观察信号写死**（调查是否坐实国家指使；议会是否辩论基地用途；政府是否调整使用条件或要求分担本土安全成本）。信号出现之前，只是预警，不是同盟已经破裂。
- 下期预告可以具体（注意力分配、回到灰区），不要空喊下期继续。
- 文末列：逮捕、保释、国籍、基地用途、否认、警方「多条线」——何者已确认，何者仍在查。不预判嫌疑人。

## 硬闸（两类共用）

1. 行为 ≠ 结果。逮捕、辞职、放话已发生；定罪、选票、通航、基地政策是否收紧，待验证。
2. 功能 ≠ 动机。操作逻辑可推演；国家指使、主动布局不可证伪就不要写成事实。
3. 方向 ≠ 幅度。叙事在争夺不是已经挂钩成功；威胁在折旧不是军事选项关闭。
4. 变量 ≠ 预测。黑箱就是黑箱。
5. 替代解释要能改写含义（主篇改时间窗口；侧翼改「刑事案件还是同盟议题」），不是对等字数，也不是一句处死。
6. 侧翼不推翻主篇主矛盾。
7. 结构判断可在个案未结时成立，但必须把「本案可能另有动机」说在明处。

## 红旗：写到这些就停

- 先写格局层/区域层/棋手棋盘
- 「真正动机是」「他最擅长」「伊朗干的」（官方未定论时）
- 把 Fairford 写成恐袭点评，或硬套 50 天、两套民调
- 把侧翼写成「英国将决定美伊终局」
- 「无论如何都会」；无变量的恐吓收束
- 口风当政策，未具名消息当官方结论

## 交稿前过一遍

- [ ] 文类选对：主篇或侧翼，没有拿错骨架
- [ ] 开篇是现场/动作，不是格局填空
- [ ] 有一句核心句
- [ ] 功能定性站住；没有「真正动机 / 最擅长」；未定论保持未定论
- [ ] 内因有肉；侧翼则内政管道分层，且接到主结构、主次未颠倒
- [ ] 替代解释能改写含义
- [ ] 收束有可核对的证伪条件或可观察信号
- [ ] 类比若用了，有相同困境 + 关键差异
- [ ] 口风/未具名消息/官方口径已经分开

## 边界

- 有理论偏好（矛盾辩证法），不装中立。
- 主要矛盾的选择是主观的，但要能被证伪条件打脸。
- 历史类比不是因果证明。
- 夹缝和侧翼只讲方向与条件，不提前宣布终局。
